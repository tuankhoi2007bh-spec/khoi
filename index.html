PERSONAL AI AGENT PROJECT · 2026

Khôi’s Lark + Hermes Agent

A personal messaging assistant connected to Lark, built to answer direct messages and provide clear, step-by-step help.

Mission

Make it easy for Khôi to talk with a personal AI assistant in Lark, with approved access and a reliable Hermes Gateway connection.

How it works

  1. Create a Lark app and enable the Bot capability.
  2. Add message permissions and subscribe to im.message.receive_v1.
  3. Publish the app and enter its credentials in Hermes.
  4. Select Lark, WebSocket, DM pairing, and group @mention behavior.
  5. Run hermes gateway run and keep the terminal open.
  6. Message the bot, then approve the current request with hermes pairing approve feishu <request-id>.
  7. Send another message to confirm the bot replies.

Inputs & outputs

Inputs: Lark direct messages, group messages that mention the bot, and approved pairing requests.

Outputs: Vietnamese replies, pairing guidance, troubleshooting steps, and optional scheduled notifications.

Tools

  • Lark Bot — chat interface
  • Hermes Agent — assistant runtime and gateway
  • WebSocket — persistent connection without a public webhook

Success criteria

  • Credentials verified and WebSocket connected
  • Khôi’s user pairing approved
  • Bot replies to a new Lark message
  • Gateway stays running during use

Safety & boundaries

  • Keep App Secret private; never paste it into chat.
  • Use the current request ID, not an example code.
  • Hide access_key and ticket values in logs.
  • Set a home chat only if scheduled notifications are needed.
  • Review generated content before relying on it.
